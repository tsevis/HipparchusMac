# HipparchusMac File Structure

**Version 0.5.0**

This document describes the repository layout of HipparchusMac, a native macOS
vector cartography application. It complements the "Layout" section of
[README.md](README.md) with a full annotated tree.

The shape to hold in mind: **the model is a Swift package and the window is a
thin app on top of it.** Anything decidable without a widget is decided in
`Sources/` and tested there; `App/` is wiring. That is why 1068 tests can run
headlessly and the layout has almost none.

## Top Level

```text
HipparchusMac/
├── README.md                  Project overview, install, and the long-form reasoning
├── MANUAL.md                  Full user manual
├── FILE_STRUCTURE.md          This document
├── CLAUDE.md                  Notes for an agent working here — read the UI-test warning
├── LICENSE                    MIT License
├── THIRD-PARTY-NOTICES.md     GEOS (LGPL-2.1) and every data source's terms
├── .github/workflows/         CI: swift test, plus the two drift checks below
├── Package.swift              Swift package: five targets, four test targets
├── Sources/                   The model — everything that is not a window
├── App/                       The macOS application and its Xcode project spec
├── Tests/                     Unit tests for the package targets
├── Scripts/                   Build, package, install, and fixture generation
├── Vendor/                    Pre-built GEOS xcframework, committed
├── Plugins/                   Style packs, loadable at run time
├── Docs/                      Long-form notes and the README's images
└── dist/                      Built disk images (git-ignored)
```

`App/HipparchusMac.xcodeproj` is **generated by xcodegen from `App/project.yml`**
and is git-ignored. Edit the spec, never the project file; `Scripts/make-dmg.sh`
regenerates it on every run.

## The package (`Sources/`)

Five targets, layered so each depends only on the ones below it.

```text
Sources/
├── CGEOS/                     System library target: the C shim for GEOS
│   └── include/               geos_c.h and a module map declaring module CGEOS
├── HipparchusGeometry/        Pure geometry. No engine, no I/O, no GEOS. (19 files)
│   ├── Coordinate.swift       Points, bounds, and the arithmetic on them
│   ├── Geometry.swift         The geometry model every layer is made of
│   ├── Smoothing.swift        Which layers may be smoothed, and how hard
│   └── SpatialGrid.swift      Bucketed lookup for label collision and joins
├── HipparchusGEOS/            The operations that need an engine. (5 files)
│   ├── Bands.swift            Filled elevation bands: polygonize, test, union
│   ├── GEOSContext.swift      One context per thread, and its lifetime
│   ├── GEOSConversion.swift   Geometry ⇄ GEOS, both directions
│   ├── GEOSOperations.swift   union, difference, buffer, pointOnSurface…
│   └── LayerSmoothing.swift   Chaikin smoothing, per layer, dimension-aware
├── HipparchusData/            Sources, fetching, decoding, provenance. (32 files)
│   ├── Attribution.swift      The credit registry, and the exempt list
│   ├── TerrainTileProvider.swift   Elevation, contours, bands, hillshade
│   ├── ERDDAPProvider.swift   Sea temperature and currents, one client
│   ├── OverpassQuery.swift    What is asked of Overpass, per layer
│   ├── OverpassDecode.swift   Tags → layers, including the road hierarchy
│   ├── FileSourceProvider.swift    Shapefile, GeoJSON, PBF, tiles from disk
│   └── …                      Seamarks, satellites, earthquakes, night lights
├── HipparchusRender/          Presets, scene building, drawing, export. (23 files)
│   ├── Presets.swift          The preset model, and every derived style
│   ├── PresetTables.swift     GENERATED from the Python. Do not hand-edit.
│   ├── PaletteSheet.swift     Seventeen palettes, over any preset
│   ├── SceneBuilder.swift     Fetched features → a drawable scene, in order
│   ├── LayerInventory.swift   What a rendered map actually contains
│   ├── PageSize.swift         Sheets in millimetres, inches and pixels
│   └── …                      SVG, PDF, PNG and GeoJSON export; labels; sea
└── hipparchus-cli/
    └── main.swift             The headless renderer. No window, no AppKit.
```

**`PresetTables.swift` is generated** by `Scripts/generate-presets.py` from the
Python repository's preset registry — five hundred lines of colour data
transcribed by hand would be five hundred chances to mistype a channel. Change
the Python, re-run the generator, commit the result.

## The application (`App/`)

```text
App/
├── project.yml                xcodegen spec. Version, entitlements, changelog.
├── HipparchusApp/
│   ├── HipparchusApp.swift    Entry point, menus, the whole keyboard
│   ├── ContentView.swift      The three-column window
│   ├── MapModel.swift         What the window knows; the bridge to the package
│   ├── MapCanvas.swift        The drawing surface, and the pen
│   ├── FramePanel.swift       The area: bounds, search, saved places
│   ├── SourcesPanel.swift     Which sources to ask, and what they cost
│   ├── LayersPanel.swift      The layer list, derived from the built scene
│   ├── CompositionPanel.swift The page: size, dpi, furniture
│   ├── StylePicker.swift      Sixteen presets, seventeen palettes
│   ├── Locator.swift          The world map, drawn from Natural Earth
│   ├── SavedPlaces.swift      Places, regions, and ~195 country boxes
│   ├── SettingsView.swift     Preferences, applied as they are made
│   ├── StateDirectory.swift   Where settings, presets and caches live
│   └── Resources/             Assets, the app icon, bundled data
└── HipparchusUITests/         XCUITest. Opens real windows — see below.
```

## Tests (`Tests/`)

```text
Tests/
├── HipparchusGeometryTests/   19 files — projection, bounds, simplification
├── HipparchusGEOSTests/        4 files — bands, smoothing, GEOS conversion
├── HipparchusDataTests/       25 files — providers, decoding, provenance
└── HipparchusRenderTests/     31 files — presets, scene, export, page, labels
```

```bash
swift test          # 1068 tests, headless, opens nothing
```

`App/HipparchusUITests/` is **not** part of that run. It drives the real
application with real system-level mouse and keyboard events, which means it
takes over the machine it runs on. Launch it deliberately with
`Scripts/ui-test.sh`, never as part of a normal check, and never while you are
using the Mac for anything else.

## Scripts (`Scripts/`)

```text
Scripts/
├── make-dmg.sh                     Build, sign ad-hoc, package → dist/
├── install-app.sh                  Install a built app into /Applications
├── ui-test.sh                      The XCUITest suite. Takes over the machine.
├── build-geos-xcframework.sh       Rebuild Vendor/geos from pinned source
├── generate-presets.py             Regenerate PresetTables.swift from the Python
├── generate-*-parity-fixture.py    Fixtures proving the two apps still agree
├── build-app-icon.py               The icon, from artwork
├── build-style-packs.py            Package the Plugins/ directories
└── update-render-figures.sh        Refresh the README's gallery images
```

The `generate-*-parity-fixture.py` scripts are how the two applications are held
together: each captures the Python's answer to a computation so the Swift can be
asserted against it, rather than the two drifting and nobody noticing.

## Vendored (`Vendor/`)

```text
Vendor/geos/
├── geos.xcframework/          libgeos.a, universal (arm64 + x86_64)
└── MANIFEST.txt               Source URL, sha256, every CMake flag, toolchain
```

Committed deliberately, so a clean clone builds with **no CMake and no network**.
GEOS is LGPL-2.1 and statically linked — see
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) for what that obliges you to do
if you redistribute a binary.

## Style packs (`Plugins/`)

```text
Plugins/
├── cartographers/    duotone-press/    high-contrast/
├── nautical/         tsevis-palette/
```

Each is a folder of JSON declaring presets, palettes and places. Point the app at
one with `--plugins <dir>`, or from Settings, and its presets can be named like
the built-in ones.

## Not in the repository

- `App/HipparchusMac.xcodeproj/` — generated by xcodegen from `project.yml`.
- `.build/` — Swift package build products.
- `dist/` — built disk images.
- `documents/`, `docs not to push/` — working notes, deliberately local.
- `out/`, `out-world/` — render output.
